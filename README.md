# Simple Interest Calculator

A Bash command-line calculator that computes simple interest from a principal
amount, annual rate of interest, and time period.

## Usage

Run the script with Bash:

```bash
bash simple-interest.sh
```

Enter the principal amount, annual rate of interest (as a percentage), and time
period (in years) when prompted. The calculator displays the simple interest.

The calculation is:

```text
simple interest = principal * rate * time / 100
```
