# Contributing

All contributions, bug reports, bug fixes, documentation improvements,
enhancements, and ideas are welcome.

## How to Contribute

1. Open an issue to describe a bug or proposed change.
2. Create a branch for your changes.
3. Keep changes focused and include clear descriptions.
4. Test the calculator with representative inputs before submitting a pull
   request.

Please be respectful and follow the project's Code of Conduct.
